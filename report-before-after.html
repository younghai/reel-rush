Tidewater 소스·알고리즘 적용 내역 (10/4 추가분)

저장소를 클론해 src 80,899줄을 정독하고, 게임 로직의 핵심 알고리즘 9종을 우리 2D 아케이드에 맞게 이식했습니다. Before(이번 적용 전 우리 구현) → After(이식 후) 공식 비교:

① 시간대 활성 곡선

B: 낮/밤 이진 (올라오거나 안 오거나)
A: dawn(6.5h)·dusk(18.5h) 가우시안 피크 — 골든아워에 활성이 연속 상승
exp(-((hour-6.5)**2)/2.5)  // dawn peak

② 수심 서식지 (신규 전략)

B: 존×시간 테이블만
A: 종별 선호 수심 밴드 + smoothstep 친화도 — 밴드 밖은 0.3폭에 걸쳐 감쇠. 깊은 캐스트에서 얕은물 어종 배제(테스트로 검증)
1 - smoothstep(lo-0.3, lo, p)

③ 입질 지연 분포

B: 균등 난수 1.6~9초
A: 지수분포(풍부한 물일수록 빠름) + 하한 1.6초 보장
2 + -ln(1-r)*mean*0.55

④ 긴장 관성

B: 홀드/해제 직접 가산 (기계적)
A: tension이 목표로 지수수렴 — 서지·지침이 관성에 반영돼 릴이 살아있음
t += (target-t)*(1-exp(-dt*rate))

⑤ 슬랙 페널티 (신규)

B: 풀어도 9초 버팀 — 방심 구간
A: 긴장 <12% 2.4초 지속 → 바늘 이탈 ("풀면 놓친다")

⑥ 트로피 스태미나

B: 종 평균 스태미나만
A: 개체 크기 스케일링 — 같은 종이라 트로피가 유의미하게 오래 버팀
staminaMax *= (kg/maxKg)**0.35

⑦ 밴드 효율

B: 밴드에서만 진행
A: 스태미나 드레인 밴드 1.0배 / 밖 0.3배 — "밴드가 3.3배 효율"이라는 메시지를 수치화

⑧ boids 어군

B: 직선 유영 7마리
A: 16마리 무리 — 분리/정렬/응집 + 배회, 속도 클램프. 2D O(n²) 예산 내

⑨ 보이스 리밋

B: 릴 클릭 개별 리미터만
A: 카테고리별 동시 상한 테이블(splash 2, snap 1, bite 1...) — 프레임당 큐 폭주 방지
의도적으로 채택하지 않은 것 — 거리(m) 기반 파이팅(우리 progress%가 2D 가독성·콤보 연동에 유리), 3D 월드·연료 시뮬(정체성 분기), 파도 위상 동기화 오디오(3D 전용). 반대로 우리의 보스 격노(서지 강화)는 Tidewater와 반대 방향이지만 보스 정체성으로 의도적 유지합니다.

왜 이렇게 오래 걸렸나 — 솔직한 분해

결론: 요청 범위가 "참고 레포 기반 게임 신규 개발 + 검증 + 감사 + 배포 + 알고리즘 이식" — 게임 스튜디오의 몇 주치 몫이었고, 시간의 상당 부분은 코딩이 아니라 검증과 환경 싸움에 쓰였습니다. 그 시간이 출시 전 잡은 버그 10건+로 전환됐습니다.
